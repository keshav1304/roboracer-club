LIMITS
Success requires passing, returning near the reference and completing follow-through. Both cars count toward collision results. Timeout is 40 seconds unless stated in the manifest. Development fixtures are distinct from fresh random validation. Selected RViz successes are demonstrations, not aggregate evidence.
This is simulated evaluation, not a guarantee of collision-free physical driving. The reference is locally optimized, not certified globally optimal. This track is the same imported default used previously; it is not a newly verified competition map.
Parallel trial timing includes perception and planning. A p95 above 50 ms misses a 20 Hz wall-clock budget. Separate serial timing, if present, should be used for speed comparisons.
